# Стандарты интеграции с внешними системами

## Обеспечение безопасности

| Критерий                | Меры реализации                                                                 |
|-------------------------|---------------------------------------------------------------------------------|
| Защита передаваемых данных | TLS 1.2+ для API, шифрование персональных данных в БД (AES-256)                |
| Управление правами доступа | OAuth 2.0 с JWT-токенами (scope: smart_home:access)                            |
| Противостояние DDoS-атакам | Лимит запросов (100 RPM на пользователя), защита через Cloudflare              |
| Мониторинг событий       | Централизованный сбор логов в Splunk для анализа API-запросов                  |
| Соблюдение 152-ФЗ        | Биометрия хранится у партнёра, передаются только хэши                          |

## Механизмы аутентификации и авторизации

**Процесс аутентификации:**
- Мобильные устройства → Keycloak (по протоколу OIDC)
- Шлюз Умного дома → API партнёра (OAuth 2.0 Client Credentials Flow)

**Система авторизации:**
- Роли пользователей:
  - Владелец (полный доступ)
  - Арендатор (ограниченные права, например открытие двери)
- JWT-токены содержат:
  - user_id
  - Список разрешений

## Схемы взаимодействия компонентов

| Компонент системы          | Протокол          | Назначение                                                                 |
|----------------------------|-------------------|----------------------------------------------------------------------------|
| Приложение ↔ Шлюз          | HTTPS/WebSockets  | Реальное управление устройствами (мгновенные команды через WebSockets)     |
| Шлюз ↔ API партнёра        | REST (JSON)       | Асинхронные операции (настройка правил доступа)                            |
| Шлюз ↔ tenant-core-app     | gRPC              | Синхронизация данных пользователей и прав доступа                         |
